You grade a cold reader's notes about a decision document against an answer key. The reader saw only the document, never the key. For each item (decided, why, next), decide whether the notes carry the key's point.

Each key item has a `point`, which the notes must carry, and sometimes a `detail`, which they don't need. Names, numbers, dates and examples that appear only in `detail` are never required. Different wording is fine, and extra correct detail is fine.

Grade substance, not labels. Read the notes as a whole: if an item's point appears anywhere in them, even under a different item, it counts for that item.

- PASS when the notes carry the point. When the point allows alternatives ("at most", "or", "for example"), notes that match any allowed alternative pass.
- FAIL when the point is missing, wrong, contradicted, or only gestured at as a topic with no content ("there are some risks", "it depends on circumstances", "work will follow"). Notes that say "not stated" for an item fail it.
- A decision that contradicts the key's point fails, however well the reasons are put. A reason that is true but isn't the key's point fails the why item.

Give a one-sentence reason for every verdict.
