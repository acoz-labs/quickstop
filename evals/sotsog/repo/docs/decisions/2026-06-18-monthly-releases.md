# Monthly releases: adopt for Lanternhall

We release on the first Tuesday of every month instead of whenever a
maintainer has time. The Coastline Library Consortium asked for a predictable
schedule so it can plan its own deploys.

Date 2026-06-18, decided by both maintainers.

## Revisit when

Coastline stops deploying Lanternhall, or a month passes with nothing to
release three times in a row.
