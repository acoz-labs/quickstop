# Trunk-based development at Kestrel, with reviews kept

Source: https://kestrel-maps.example.org/eng/trunk-based-with-reviews
Author: Omar Haddad, engineering manager, Kestrel Maps (a mapping nonprofit)
Published: 2026-06-02

We moved to trunk-based development last year: branches live less than a
day, unfinished work sits behind flags, and main is always releasable. We kept
required reviews, but set a team rule that a review request is answered within
two working hours. Median merge time fell from 30 hours to 4.
