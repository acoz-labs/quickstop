# Release 24.11 plan

Ships: 19 November.

- Remove the v1 REST endpoints (`/api/v1/*`). They were deprecated in 24.6 with a 5-month notice.
- Remove the v1 static-token authentication path that only v1 uses.
- Bump the client SDK to 5.0 (v2 only).

Next release after this one: 24.12, about six weeks later (early January).
