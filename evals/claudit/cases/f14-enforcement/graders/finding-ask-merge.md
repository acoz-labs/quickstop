CLAUDE.md says never to merge to main without a human approving the pull request (`gh pr merge`), but `.claude/settings.json` has no `ask` or `deny` rule, so the gate is prose only.

PASS when the report adds an ask rule for the command: a JSON `"ask": [...]` array holding `"Bash(gh pr merge`, or one line with "ask" (or `permissions.ask`), `Bash(gh pr merge` and a recommending word (add, put, move, use, set, create, include, list, register, gate, require, should, recommend, or Claudit's "Change"; not the "gate" in "human-gate"). A hypothetical such as "an ask rule would do it" is not a recommendation.

Script-graded (case-insensitive). The parts, and the controls each must pass and fail, are in `tests/test_claudit_fixture_graders.py`; rebuild with `python3 tests/test_claudit_fixture_graders.py --write`. A line never counts when it is a `Source:` citation line, a question (it has "why not" or a `?` before a space or the line end), or when a negation directly governs the finding ("no ask rule is needed", "not a symlink"; a negation elsewhere on the line doesn't count) or it says the fix is already in place.
