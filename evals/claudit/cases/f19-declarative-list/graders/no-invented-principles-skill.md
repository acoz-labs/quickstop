`docs/principles.md` is a numbered list of standing principles with no imperative verbs or sequence words. It is not a procedure, so no skill is needed (issue #192 F15, a false-defect grader like F4).

Must not match: a line naming the principles that recommends a skill (add, create, make, turn, convert, move, wrap, extract, package, write, promote or split, then "skill" within 60 characters; "skill for … principles"; needs/deserves/warrants/should be/belongs in a skill or command), calls it a procedure, or names `SKILL.md`, a slash command or `.claude/skills/`. A negated clause ("not a procedure", "no skill is needed") is skipped; "why not" is never a negation.

Script-graded (case-insensitive). The parts, and the controls each must pass and fail, are in `tests/test_claudit_fixture_graders.py`; rebuild with `python3 tests/test_claudit_fixture_graders.py --write`. A line never counts when it is a `Source:` citation line.
