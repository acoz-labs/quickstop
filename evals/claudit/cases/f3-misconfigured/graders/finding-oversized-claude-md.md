The fixture's `CLAUDE.md` is about 240 lines, well over the recommended 200-line target, and almost all of it restates the source code function by function. Only a few lines carry information the code cannot: the commands (`npm test`, `npm run lint`), Node 20+/ESM, "never store money as a float", "no runtime dependencies", "add a test before changing a tax rate".

Script-graded (case-insensitive). One change item names `CLAUDE.md`, states its size, and says to cut it. The size is a line count of 201 or more (also `1,240 lines`) or "over/more than/above/exceed(s)/past/beyond/longer than (the) (recommended) 200 (lines)". The cut is cut..., trim..., shorten..., reduc..., drop..., delet..., remov..., condens..., slim..., prun..., strip..., "pare", "rewrite (it) down/shorter"; "move (the/its) (up to three words) notes/sections/details/content/text/walkthroughs/descriptions/procedures … into/to/out … (code) comments/skills/rules/docs/README"; "replace … with/by … short…/N-line/condensed/trimmed/leaner/smaller"; or "keep it/CLAUDE.md/only … to/only/under". A change item ends where a blank line is followed by a column-0 line, or at a column-0 numbered item, `#` heading or `-`/`*`/`+` bullet, so an item's title, Problem, Why and Change lines and its fenced blocks are one unit.

The grader doesn't check that the report says the file restates the code; that part of the old judged rubric is no longer graded. "Under 200 lines" alone isn't a size, and a size in one item with a cut in another fails.
