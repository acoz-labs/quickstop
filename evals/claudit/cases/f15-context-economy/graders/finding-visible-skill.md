`.claude/skills/schema-rules/SKILL.md` is read only by the `migrator` subagent (by path), but it is model-invocable, so its description loads in every session.

PASS when the report hides it: a line naming `schema-rules` and `disable-model-invocation` (not set to false), a frontmatter snippet with `name: schema-rules` and `disable-model-invocation: true`, or a line that moves (inlines, folds, merges, puts, copies) `schema-rules` into the `migrator` subagent. `user-invocable: false` keeps the description loaded and does not count.

Script-graded (case-insensitive). The parts, and the controls each must pass and fail, are in `tests/test_claudit_fixture_graders.py`; rebuild with `python3 tests/test_claudit_fixture_graders.py --write`. A line never counts when it is a `Source:` citation line, a question (it has "why not" or a `?` before a space or the line end), or when a negation directly governs the finding ("no ask rule is needed", "not a symlink"; a negation elsewhere on the line doesn't count) or it says the fix is already in place.
