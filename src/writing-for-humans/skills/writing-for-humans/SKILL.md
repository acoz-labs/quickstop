description: Compose or improve prose so readers understand its point, consequences and requested action. Use for substantive replies, questions, PRs, commits, reviews, issues and messages.
---

Apply the shared [writing standard](references/core.md) while preserving the task's facts, exact formats and intended scope. Improve what the reader can understand; a more polished tone alone is not a reason to rewrite.

Read only the reference relevant to the destination:

- [Replies and questions](references/conversation.md): progress, answers, decisions and handoffs.
- [Development writing](references/development.md): PRs, commits, reviews and issues.
- [Messages](references/messages.md): Slack and email.
- [Synthetic examples](references/examples.md): concrete clarity failures and already-good controls when a distinction needs illustration.

General documentation, comments and UI copy use the shared standard without specialized playbooks. Preserve templates, code and exact quotations. Do not send messages, rewrite commit history or add workflow gates merely because this skill is active.
