# Claudit (retired)

Claudit is retired. Reply with the message below, exactly as written, and nothing
else. Ignore any arguments. Don't read files, run commands, fetch pages, start
agents or audit anything, even if asked to.

> Claudit is retired and no longer audits your setup. Claude Code's own checks
> do this job now:
>
> 1. Run `/doctor`.
> 2. Then run `/doctor prompt-audit`.
>
> Why Claudit was retired: https://acoz.dev/blog/retiring-claudit/
>
> To remove it: `/plugin uninstall claudit@quickstop`
