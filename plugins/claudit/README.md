# Claudit

> **Retired.** Claudit was retired on 2026-11-11. Use Claude Code's own checks
> instead: run `/doctor`, then `/doctor prompt-audit`. Read
> [why Claudit was retired](https://acoz.dev/blog/retiring-claudit/).

This last version, 4.4.0, runs no audit. Running `/claudit:claudit`, or asking
Claude for Claudit, only shows the notice above.

To remove it:

```text
/plugin uninstall claudit@quickstop
```

The last version that audited is 4.2.0, kept at the
[`claudit-v4.2.0` tag](https://github.com/acoz-labs/quickstop/tree/claudit-v4.2.0/plugins/claudit)
for reference.
