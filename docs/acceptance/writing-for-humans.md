# Writing for Humans kit acceptance

This procedure applies to the Claude Code-only conversion of the original shared kit in issue129. The cross-platform experiment and its v1/v2/v3 research protocols are archived; their failed outcomes remain historical failures. This is a conversion and distribution check, not a claim of general superiority over modern models.

## Conversion fidelity

Independently compare the retained original kit with the package. Account for every material difference: native metadata and selection, preserved coding instructions, package-local references, explicit task/repository/authorization precedence, removed orchestration mandates, bounded optional cold-reader use, and independently invented public examples. Preserve the substantive context-independence and evidence-placement guidance and clearly label the opinionated voice. Keep original ZIPs and private configuration out of public artifacts.

## Native use

Install retained exact package bytes in an isolated Claude configuration. Begin with another selected style and an unrelated setting; installation must preserve them. Verify discovery of the output style and both skills, then use the native selector and a fresh session to confirm the intended style is active. Verify coding instructions are preserved and all references resolve from the installed package. No lifecycle hooks or runtime dependencies should appear.

Use a small, fixed set of independently synthetic writing examples covering an explanation with evidence, a question with a consequence, and an already-clear control. Compare the converted plugin with the original kit under matched native model/effort settings and inspect actual output for understandable meaning, retained facts and the intended style. Record any normalization of the original fixture needed for native compatibility. This is bounded conversion evidence; do not tune prompts until a preferred result appears or turn it into the abandoned multi-harness benchmark. Have one actual human compare the original and converted output for the prespecified question example, with the condition labels withheld. Record whether the point, choice and consequence are understandable and whether the conversion retains the kit’s useful character. This small qualitative check is not a population study or a claim of universal improvement.

Exercise the audit on a synthetic local draft with explicit local-only authorization. Inspect what it changes and any tool calls. It must preserve substantive facts and respect external publication/history boundaries. A reviewer must inspect outcomes; discovery or instruction delivery alone is not a pass.

Select another style, disable and uninstall the package, and verify a fresh session has no active plugin style or skills while unrelated settings remain intact. Document retained prior conversation context and any stale explicit style selection instead of inventing restoration. Record tested host/model versions and modes; independent subagent coverage is not claimed.

## Artifact delivery

Run bin/ci and native package validation independently in a clean checkout. Retain the exact merged source archive and package digest, nominate it with the complete implementation set, and record actual issue-specific and configured SDLC acceptance criteria with openable sanitized evidence.

Promote only those accepted bytes through the existing release lock and native marketplace. Verify the downloaded release artifact, advertised full commit, installed package digest, style selection and a fresh consumer writing task. First-release recovery removes only the Writing for Humans advertised entry and explains native style deselection/removal; retain immutable artifacts. Preserve Claudit and the marketplace's optional support for other harnesses.
