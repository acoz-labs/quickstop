# Writing for Humans acceptance

Run independently from contributor tests against retained immutable packages. Record source commit, per-target package digest, installed digest, host/model versions, configuration and execution mode with sanitized evidence. All inputs, outputs and configuration fixtures must be independently synthetic. Never publish private configuration or personal incidents.

## Installation and runtime

For each target, install the candidate through the native mechanism in a clean temporary consumer configuration. For Claude Code, preserve an existing output style and verify SessionStart, UserPromptSubmit and SubagentStart. For Codex, verify the Codex compatibility manifest hooks declaration loads SessionStart and SubagentStart, then complete native hook trust review; disabled or untrusted hooks must not be reported active. For Pi, verify the package extension and both skills load and preserve a preceding extension's prompt contribution.

Separate installed, enabled, trusted, loaded and behavior-verified states. Record runtime prerequisites and tested operating systems/modes. Do not infer app/editor coverage from CLI tests. Exercise first output, resume, compaction during a tool-heavy turn and direct prose from supported independent subagents. Pi core has no general native independent-subagent interface; separately record any third-party orchestration tested. An available path that bypasses guidance remains an unresolved coverage gap.

Verify setup before and after installation, reruns, duplicate installations, missing resources, update, disabling and uninstall. Preserve unrelated user settings and selected styles. Confirm runtime handlers read only bundled text and perform no network calls or consumer writes. Native trust must not be bypassed. Start fresh sessions when checking removal because existing conversations can retain earlier guidance. No routine configuration edits are implemented; test diagnostic recommendations against synthetic native states without manufacturing a need to edit files.

## Writing behavior

Use the independently calibrated, frozen evaluation protocol with matched baseline and candidate tasks. Read model outputs; instruction delivery alone does not pass. Cover ordinary replies, progress, questions, handoffs, PRs, commits, reviews, issues and captured local draft fields representing GitHub, Linear and Slack. Never send evaluation messages to real recipients.

Include the named clarity failures, already-good controls, missing facts, technical vocabulary, shared and missing context, quoted material, exact JSON/schema fields, required trailers, explicitly authorized code changes and language boundaries. Preserve whether verification was proposed, exists or was observed passing. Independent readers restate meaning using only the intended reader's context; check facts separately against full synthetic facts. Correct and retest invented facts, missing qualifications, damaged exact formats and unauthorized actions.

Record wins, losses, ties, denominators, disagreements and per-surface results, plus latency, token overhead and reference reads. Freeze repeat rules and acceptance thresholds before final evaluation; do not tune thresholds to make the candidate pass. Report tested language limits and any remaining coverage gaps.

## Publication and consumer verification

Use the accepted-artifact workflow in [delivery](../delivery.md). Candidate catalog declarations alone must not advertise these packages. After independent acceptance, promote the exact accepted source revision and package digests through the release lock, regenerate native listings and verify clean installations from the advertised sources.

For Pi, install from a separate detached checkout of the accepted revision; upgrading an old local path does not select new accepted bytes. Verify every installed package digest and native activation after publication. Keep the release issue open until all three targets pass. First-release rollback removes only the new advertised entries, preserves Claudit and retains immutable artifacts and acceptance evidence; document native uninstall/cache recovery.
