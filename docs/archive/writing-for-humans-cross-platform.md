# Archived cross-platform Writing for Humans experiment

The owner stopped the cross-platform experiment on 2026-09-22 and replaced it with [issue129](https://github.com/acoz-labs/quickstop/issues/129), a faithful Claude Code-only conversion of the original shared kit.

The old implementation remains at [source5d5ec3598e032010e0da766f6f2bb652c10a72bc](https://github.com/acoz-labs/quickstop/tree/5d5ec3598e032010e0da766f6f2bb652c10a72bc), tagged `archive/writing-for-humans-cross-platform-2026-09-22`. [Issue122](https://github.com/acoz-labs/quickstop/issues/122) is closed as not planned, with its plans, PR references and failed acceptance preserved. No candidate from that experiment was accepted or advertised. The v3 final evaluation never ran.

Original configuration and kit ZIPs, retained artifacts and private research evidence remain archived outside this public repository. Do not publish those directories wholesale: native test fixtures can contain private account state. Public examples for the new plugin are independently authored.

The old shared-source generator, Writing for Humans runtime hooks and its Codex/Pi target packages are removed from active development. They can be recovered from the archive if a future task justifies them. General marketplace support for Claude Code, Codex and Pi remains; support is optional per plugin. The accepted-artifact publication mechanism from [issue123](https://github.com/acoz-labs/quickstop/issues/123) is retained for the new kit and other plugins.

Historical failures are not retroactively passed or inherited as acceptance claims for the different kit conversion. Do not resume the old prompt-tuning program under the new issue.
